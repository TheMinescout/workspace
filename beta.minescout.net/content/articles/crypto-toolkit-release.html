RELEASE: Minescout Crypto Toolkit

SEP 29, 2026 · CRYPTOGRAPHY SUITE · SINGLE-FILE UTILITY

System entry / tool deployment

We have assembled the classical cryptography tools into one deployment: the Minescout Crypto Toolkit. Everything runs locally in a single HTML file — no build step, no network calls, no dependencies.

Classical ciphers are the fastest way to understand why modern encryption works. Each cipher in this toolkit is a small, breakable lesson — and breaking it is the exercise.

Why classical ciphers

Every cipher in this release was once considered unbreakable. The Caesar shift guarded Roman military correspondence. Atbash appears in the Hebrew Bible. The Vigenère cipher held the title "le chiffre indéchiffrable" for three centuries — until frequency analysis and the Kasiski examination ended its reign. Working with tools you can actually break teaches more about cryptographic strength than any modern library ever will, because you get to watch the failure modes happen.

What's inside v1.0

  • Caesar cipher with an interactive shift slider — scrub through all 25 shifts and watch the plaintext emerge, plus a one-click brute-force of the full keyspace.
  • ROT13 and Atbash — the self-inverse classics, included because every toolkit needs its quick wins.
  • Affine cipher with full key validation (rejects multipliers not coprime with 26) and working decryption via modular inverse.
  • Frequency analysis — a live letter-frequency chart that overlays your ciphertext against average English, the analytical core of the whole suite.
  • Semi-automated substitution solver — frequency-seeded initial mapping, a 26-letter hand-tuning grid, and a common-word brute list that flags candidate decryptions.
  • Vigenère bridge — the existing standalone Vigenère tool links in as the polyalphabetic tier: use the frequency chart here to estimate key length, then finish the attack there.

How to break things, in order

  1. Start in the Frequency tab. Flat, noisy letter distribution? Polyalphabetic — go to Vigenère. Spiky distribution that looks like scrambled English? Monoalphabetic — continue.
  2. Try Caesar brute first. It's free. 25 candidates, one click.
  3. No luck? Open the Substitution solver, seed the mapping from frequency, then swap letters by hand using the plaintext preview until words appear.
  4. Stuck on a Vigenère ciphertext? Count the coincidence gaps in the frequency chart to guess the key length, then run the dictionary attack in the Vigenère tool.
