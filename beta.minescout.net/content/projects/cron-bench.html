    How this works

    The rules this bench implements, and the ones it deliberately does not.

    *Every value in the field.
    5One value.
    1-5An inclusive range.
    1,15,30A list of values, ranges or steps.
    */15Every 15th value from the start of the field.
    10-40/10Every 10th value inside a range.
    JAN / MONMonth and weekday names. Weekdays run SUN to SAT; 7 is also Sunday.
    @dailyMacro for 0 0 * * *. Also @hourly, @weekly, @monthly, @yearly.

    Day matching follows the POSIX rule. When both day-of-month and day-of-week are restricted, a day matches if either field matches. When one of them is a plain *, only the other field decides. A schedule such as 0 0 31 2 * is valid syntax that never fires, and the bench says so instead of inventing a date.

    Everything is evaluated in this browser against your local clock, including daylight-saving transitions, because the preview is built from real local dates. There is no seconds field, no @reboot, and no network call of any kind: the page has no dependencies and works from a local file.
