Claude My #1
★★★★★
AI Assistant
Free / Pro

Claude is the AI I reach for first, every time. It writes cleaner code, explains things more clearly, and handles long conversations without losing context. I use it for everything — building this site, writing proposals, debugging Workers, and thinking through problems. Anthropic's focus on being genuinely helpful rather than just agreeable makes it feel more like a collaborator than a chatbot.

Works well for
Code, long documents, nuanced writing, complex multi-step tasks, anything where accuracy actually matters.
Watch out for
Free tier has message limits. Doesn't browse the web unless you use the paid version with tools enabled.
Try Claude

Perplexity
★★★★★
AI Research & Search
Free / Pro

Perplexity replaced Google for me on anything research-related. It gives cited, sourced answers instead of a list of links to click through. When I'm researching a business before pitching them, or need to understand a technical concept quickly, Perplexity is faster and more useful than any search engine. The sources panel means I can always verify what it's telling me.

Works well for
Current events, research with citations, quick fact-finding, comparing options without opening 10 tabs.
Watch out for
Not great for creative tasks or long-form writing. Pro is worth it if you search a lot, but free covers most use cases.

ChatGPT
★★★★★
AI Assistant
Free / Plus

I use ChatGPT when I need image generation (DALL-E), or when I want a second opinion on something Claude gave me. It's capable and the free tier is generous, but for most writing and coding tasks I find Claude more precise and less prone to confidently wrong answers. Still a strong tool — just not my first pick anymore.

Works well for
Image generation via DALL-E, brainstorming, casual conversation, voice mode on mobile.
Watch out for
Can be overconfident with wrong information. I prefer Claude for anything where accuracy is critical.
Try ChatGPT
💫
Gemini
★★★★★
AI Assistant
Free / Advanced

Gemini is Google's AI and it's genuinely good — especially for anything that benefits from Google integration (Docs, Sheets, search). I use it for generating CSV data, working inside Google Workspace, and tasks where I want the Google ecosystem plugged in. It's not my daily driver, but it earns its place in the rotation for specific jobs.

Works well for
Google Workspace integration, generating structured data, tasks tied to Search or Maps context.
Watch out for
Personality feels more corporate than Claude or ChatGPT. Not as strong on creative or nuanced writing tasks.
Try Gemini
⚙️
Google AI Studio
★★★★★
Developer / API Playground
Free

AI Studio is where I go to prototype system prompts and test API calls before wiring them into real projects. It's a free browser-based playground for Gemini's API — you can test different models, adjust parameters, and see raw responses without writing any backend code. Essential for anyone building AI-powered apps on a budget.

Works well for
Testing prompts, experimenting with API parameters, prototyping before committing to code. Completely free.
Watch out for
It's a dev tool, not a polished product. Not useful if you're not building something. Rate limits on free tier.
Try AI Studio
🎨
Canva AI
★★★★★
Design
Free / Pro

Canva is the fastest way to produce a polished graphic if you're not a designer — and the AI features (Magic Write, background remover, image generation) make it genuinely useful. I use it for social graphics, pitch decks, and quick mockups. Honest caveat: the AI image outputs can feel generic if you're not specific with prompts, and heavy Canva use tends to make things look the same.

Works well for
Quick presentations, social graphics, removing backgrounds, anything where speed matters more than originality.
Watch out for
AI image outputs feel generic. Everything looks like Canva if you use default templates. Not a substitute for real design work.
Try Canva affiliate link

GitHub & GitHub Pages
★★★★★
Dev / Version Control / Hosting
Free

GitHub is non-negotiable for any serious project. Version control means I can experiment without fear, roll back mistakes, and keep a full history of every change. GitHub Pages is how I host static sites for free — including early versions of Minescout. If you're building anything in code and not using Git, start today.

Works well for
All code projects. Free static hosting via Pages. Version history, collaboration, and backup all in one place.
Watch out for
Learning curve for Git if you've never used it. GitHub Pages has limits for dynamic sites — fine for static HTML/CSS/JS.
Try GitHub
Tools I tried — not for me
🔑
GitHub Copilot
I wanted to like it, but inline autocomplete in the editor never clicked for me the way a proper chat interface does. I'd rather describe what I want and get a full solution than tab-complete my way through code. If you love in-editor suggestions it might work for you — it just wasn't my workflow.
🐢
Replit
Good concept — browser-based coding with AI assistance — but I found it too slow and too limited compared to working locally with VS Code and deploying via Cloudflare. The AI features felt bolted on rather than integrated. Might be useful for someone who can't install anything locally, but it's not for me.
