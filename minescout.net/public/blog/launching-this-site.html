Launching This Site — What I Built and Why

February 21, 2026 Building

I've been wanting a personal corner of the internet for a while. Not just a GitHub profile or a project page — something that actually felt like me. This is that thing.

I started building Minescout a couple years ago, and that became its own thing. But I never had a place to put the rest of it — the robotics work, the Eagle Scout stuff, the running, all of it. So I built this site.

What's on it

There's a work page that lists my projects, a resume that mirrors my actual CV, a guestbook powered by Firebase, and now this blog. The whole thing is plain HTML and CSS — no framework, no build step, no CMS. Just files.

The constraint of plain HTML makes you think carefully about every element you add. It's a good constraint.

I'm genuinely happy with how it turned out. The design is warm and editorial — inspired by my dad's site — and it actually feels like something I made, not something that was generated.

What I learned

CSS custom properties are incredibly powerful when you commit to them from the start. The whole site shares one set of variables and it makes everything consistent without any effort. I also got a lot better at thinking about mobile layout — the hamburger menu took a few attempts to get right.

More to come. I'll keep updating the Now page and writing here when something's worth writing about.
