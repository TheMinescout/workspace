Case Study: Infrastructure

Minescout Genesis: Architecting a Multi-Tenant Network

March 9, 2026 Engineering

Seventeen days ago, Minescout AI was a vision on a PDF. Today, it is a fully operational serverless engine powering a network of "nodes" for the Sammamish community. This journey was defined by a critical pivot: the shift from building individual websites to engineering a **Multi-Tenant SaaS Platform**.

The Multi-Tenant Engine

The original plan assumed a traditional agency model. But as development progressed, I recognized a massive opportunity for efficiency. By utilizing Cloudflare Workers and KV storage, I architected a proprietary routing system using X-Site-Id headers.

This allows one single serverless "brain" to host an unlimited number of clients. Each node—whether it’s a theater portfolio or a writer's blog—receives its own secure data stream while sharing the same high-performance core.

Node 01: EchoStream CMS (JaymeCarleton.com)

The first challenge was the "Filter-Proof" problem. How can a writer update a site from within restricted network environments? I built the EchoStream CMS—a secure bridge that syncs Google Docs directly to a React SPA. This eliminated the need for complex administrative logins and ensured 100% editorial freedom regardless of network filters.

Node 02: Artistic Reasoning (FernCarleton.com)

The launch of Fern Carleton's studio node proved the engine's visual flexibility. While sharing the same backend logic, the frontend was remodeled to reflect "Art and Reasoning"—featuring high-detail watercolor washes and deckled edges. Last night, we cleared the final hurdle: a 1014 DNS Handshake, successfully verifying a custom domain across different account tiers.

The Road to Day 100

With the infrastructure hardened and the first two nodes in production, Phase 1 is complete. We are currently 17% through the 100-day roadmap, but we have completed nearly 50% of the technical complexity required for a global launch.

The Minescout network is now live, global, and ready to onboard its first external charter partners. We didn't just build a website; we built a delivery system for the community.

Thomas Carleton is the Lead Architect of Minescout AI. He is an FRC Robotics Engineer and maintainer of the Sammamish Multi-Tenant Node network.
